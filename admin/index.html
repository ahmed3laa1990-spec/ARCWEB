لوحة تحكم الموقع

الدخول إلى اللوحة

تحتاج رمز وصول من GitHub لحفظ التعديلات على الموقع.

  1. افتح إنشاء رمز وصول دقيق
  2. في Repository access اختر Only select repositories ثم ARCWEB
  3. في Permissions → Repository اضبط Contents على Read and write
  4. أنشئ الرمز وانسخه والصقه هنا
الرمز يُحفظ في متصفحك فقط ولا يُرسل إلا إلى GitHub. لا تشاركه مع أحد.
